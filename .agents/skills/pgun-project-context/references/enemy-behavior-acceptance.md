# 敌人行为重写验收文档

验收对象是 `EnemyBrain` 替换旧 `Follow` / `Attack` 直线追击后的敌人行为。代码已落地，验收在 Unity 编辑器内执行。逐项核对，任何一项不通过即停止验收并记录原因。

## 前置条件

以下操作未完成时，验收无法开始。

1. 计划一与计划二的 Unity 操作完成：Root 场景的 `LuaManager` 与 `PgunLuaRuntimeBootstrap`，`WeaponManager` 与对象池，CSV 导入生成的 Data Lua，GameScene 换用 `RandomRoomGenerator`，房间预制体带 `Floor` 与 `Walls` Tilemap。
2. 热修名单加入了 `EnemyBrain`。执行 `XLua/Generate Code`，等编译完成，再执行 `XLua/Hotfix Inject In Editor`。
3. `Assets/csv/EnemyData.csv` 中的视野与分离参数为种子值（视野半径 7、角度 120、追踪 2 秒、分离 1.8 与 1.5），验收前可先按手感调整。

## 已知限制

- `EnemyData` 的 `attackInterval` 当前作为 `EnemyBat` 与 `EnemyBig` 的攻击冷却（种子值 1 秒）；`EnemyA` 的射速沿用预制体上的 `shootInterval`（0.2 秒）以保持迁移前手感。统一进表时替换并调值。
- 四个敌人预制体上的旧走位字段（`followDuration`、`followBeforeAttackTime`、`playerSafeDistance`、`attackDuration` 中未复用部分）保留待手感核对后删除。
- 视野与分离参数是种子值，需要按手感调整 `Assets/csv/EnemyData.csv`。
- 近战 `RequestAttack` 保留为检测器的回调占位，实际出手条件由 `CanAttack` 每帧轮询检测盒。
